# 资料库使用说明

## 当前资料目录

- `/plan/`：项目阶段计划和进度。
- `/about-dev/`：开发架构、B 电脑操作和同步说明。
- `/.agent-state/`：每台执行节点的运行状态和任务结果。

## 推荐同步方式

将这些文件放入试点项目的 Git 仓库，A、B 使用同一个远程仓库：

```text
B：拉取 → 执行 → 更新文件 → 提交 → 推送
A：拉取 → 查看状态 → 修改任务说明 → 提交 → 推送
```

当前工作目录还不是 Git 仓库，也没有远程地址。因此本资料已经建立，但尚未具备跨电脑自动同步能力。配置 Git 远程仓库后，B 才能直接拉取和回写这些文件。

## 后续调度中心

当任务数量增加后，`.agent-state/` 的部分内容迁移到调度中心数据库；计划和操作说明仍保留在仓库中，作为可审查的项目资料。
